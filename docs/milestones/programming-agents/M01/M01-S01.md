- [x] Propagar contexto no socket, jobs, ferramentas, providers e artefatos sem inferir correlação por horário.
- [x] Versionar catálogo com causa, status, duração, tentativa e erro estruturado.

- [x] Toda ação tem identificador estável e pai rastreável; eventos de início de conversa podem não ter projeto antes de selecioná-lo.

- [x] Contrato tolera eventos de versões anteriores e consumidores ignoram campos novos.
- [x] Não existe promessa de capturar cadeia de pensamento interna.

## Telemetria obrigatória

telemetry_span_started, telemetry_span_finished, decision_recorded.

Aplicar o [contrato transversal](../TELEMETRY.md): correlação, versão efetiva, tentativas, duração, resultado/erro, redaction, acesso e retenção. Para operações com efeito, persistir intenção e recibo; resultado incerto deve ser reconciliado. Testes devem consultar os eventos persistidos, não apenas verificar que um callback foi chamado.

## Falhas e compatibilidade
